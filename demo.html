🚀 快速开始

⚠️ 重要提示： 使用前需要先配置高德地图 API Key

第一步：获取高德地图 API Key

  1. 访问高德开放平台
    打开 https://lbs.amap.com/
  2. 注册并登录
    如果还没有账号，需要先注册一个账号
  3. 创建应用
    进入控制台 → 应用管理 → 我的应用 → 创建新应用
  4. 添加 Key
    在应用中添加 Key，选择 "Web端(JS API)"
  5. 复制 Key
    复制生成的 API Key，准备配置到项目中

第二步：配置 API Key

编辑 index.html 文件，找到以下代码：

<script type="text/javascript" src="https://webapi.amap.com/maps?v=2.0&key=YOUR_AMAP_KEY"></script>

将 YOUR_AMAP_KEY 替换为你刚才获取的 API Key。

第三步：启动服务器

选择以下任一方式启动 HTTP 服务器：

方式 1：使用启动脚本（推荐）

# Linux/Mac ./start.sh # Windows start.bat

方式 2：使用 Python

python3 -m http.server 8000

方式 3：使用 Node.js

npm start

第四步：访问应用

打开浏览器访问：http://localhost:8000

📖 使用指南

基本操作

  • 开始追踪：输入车辆信息，点击"开始追踪"按钮，系统将模拟车辆移动
  • 停止追踪：点击"停止追踪"停止实时追踪，数据将保留
  • 清除轨迹：清除所有轨迹数据和地图标记
  • 轨迹回放：对已有轨迹进行回放演示
  • 加载示例：快速加载预设的示例路线
  • 随机路线：生成随机测试路线

统计信息

系统会实时显示以下统计数据：

  • 总里程（千米）
  • 轨迹点数量
  • 平均速度（千米/小时）
  • 当前状态

轨迹列表

在右侧面板会显示最近的轨迹点信息，包括：

  • 时间戳
  • GPS 坐标（经纬度）
  • 瞬时速度

🔧 技术栈

  • 前端：原生 JavaScript (ES6+)
  • 地图：高德地图 JavaScript API 2.0
  • 样式：CSS3 + Flexbox
  • 架构：面向对象编程 (OOP)

🎨 自定义配置

你可以通过修改配置来自定义系统行为：

修改默认地图中心

编辑 js/map.js：

this.defaultCenter = [116.397428, 39.90923]; // [经度, 纬度]

修改追踪更新频率

编辑 js/vehicle.js：

this.trackingInterval = setInterval(() => { // ... }, 2000); // 毫秒，2000 = 2秒

修改轨迹颜色

编辑 js/map.js：

strokeColor: '#667eea', // 轨迹线颜色
