🚀 快速开始
-----------------------------------------
1. 获取高德地图 API Key
   访问：https://lbs.amap.com/

2. 配置 API Key
   编辑 index.html，替换 YOUR_AMAP_KEY

3. 启动服务器
   ./start.sh  (Linux/Mac)
   start.bat   (Windows)
   或
   python3 -m http.server 8000

4. 访问应用
   http://localhost:8000

-----------------------------------------

  - clearTrack() : 清除轨迹

VehicleTracker  : 车辆追踪类
  - startTracking() : 开始追踪
  - stopTracking() : 停止追踪
  - startPlayback() : 开始回放
