## 🚀 快速开始

### 环境要求
- Node.js >= 14.0.0
- npm >= 6.0.0 或 yarn >= 1.22.0
- 现代浏览器（Chrome、Firefox、Safari、Edge）

### 安装步骤

#### 1. 安装依赖

```bash
# 使用 npm
npm install

# 或使用 yarn
yarn install
```

#### 2. 配置高德地图 API Key

编辑 `index-react.html` 文件：

```html
<script src="https://webapi.amap.com/maps?v=2.0&key=YOUR_AMAP_KEY&plugin=AMap.Driving,AMap.Geocoder,AMap.Geolocation"></script>
```

将 `YOUR_AMAP_KEY` 替换为你的高德地图 API Key。

**如何获取 API Key：**

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册并登录账号
3. 进入 控制台 -> 应用管理 -> 我的应用
4. 创建新应用，添加 Key（选择 Web 端 JS API）
5. 复制 Key 并替换到项目中

**安全密钥配置（可选）：**

```javascript
window._AMapSecurityConfig = {
  securityJsCode: 'YOUR_SECURITY_CODE',
};
```

#### 3. 启动开发服务器

```bash
# 使用 npm
npm run dev

# 或使用 yarn
yarn dev
```

项目将自动在浏览器中打开 `http://localhost:3000`

#### 4. 构建生产版本

```bash
# 使用 npm
npm run build

# 或使用 yarn
yarn build
```

构建完成后，生产文件将在 `dist` 目录中。

## 📖 使用指南

### 基本操作流程

#### 1. 添加车辆
1. 在左侧控制面板输入车牌号（如：京A12345）
2. 可选输入车辆名称
3. 点击"添加车辆"按钮
4. 或点击闪电图标自动生成车牌号

#### 2. 开始实时追踪
1. 在下拉列表中选择车辆
2. 点击"开始追踪"按钮
3. 系统将自动模拟车辆移动
4. 地图上实时显示轨迹路径

#### 3. 查看统计信息
1. 切换到"统计信息"标签页
2. 查看总里程、平均速度等数据
3. 查看停车点和超速警告
4. 查看当前位置详细信息

#### 4. 轨迹回放
1. 确保车辆有轨迹数据
2. 点击"开始回放"按钮
3. 使用速度选择器调整回放速度
4. 拖动进度条跳转到指定位置
5. 点击"暂停回放"可暂停
6. 点击"停止回放"结束回放

#### 5. 加载示例路线
1. 选择一个车辆
2. 点击示例路线按钮（北京市区、上海外滩、广州塔）
3. 系统自动加载预设路线
4. 或点击"生成随机路线"创建随机轨迹

#### 6. 导出轨迹数据
1. 选择有轨迹数据的车辆
2. 点击导出按钮（JSON、CSV、GPX）
3. 选择导出格式
4. 文件自动下载到本地

### 高级功能

#### 地理定位
- 点击"获取位置"按钮获取当前GPS位置
- 系统自动添加到车辆轨迹中

#### 历史轨迹查询
1. 点击"加载历史轨迹"按钮
2. 选择时间范围
3. 系统模拟加载历史数据

#### 多车辆管理
1. 在"车辆列表"标签页查看所有车辆
2. 点击车辆卡片切换选中车辆
3. 点击删除按钮移除车辆

#### 主题切换
- 点击右上角的灯泡图标
- 在亮色和暗色主题间切换

## 🎯 核心功能说明

### VehicleStore (状态管理)
使用 Zustand 管理全局车辆状态：
- 车辆列表管理
- 选中车辆状态
- 追踪状态控制
- 回放状态控制
- 告警信息管理

### TrackingService (追踪服务)
提供车辆追踪相关服务：
- 实时位置模拟
- 历史轨迹查询
- 地理编码/逆地理编码
- 当前位置获取
- 附近车辆查询

### MapUtils (地图工具)
提供地图计算相关功能：
- 距离计算
- 速度计算
- 路径平滑
- 点位插值
- 边界计算

### VehicleUtils (车辆工具)
提供车辆数据处理功能：
- 车辆ID生成
- 车牌号生成
- 数据导出
- 统计计算
- 告警检测

## ⚠️ 注意事项

1. **API Key 配置**: 必须配置有效的高德地图 API Key 才能正常使用
2. **HTTPS 要求**: 生产环境建议使用 HTTPS 协议
3. **跨域配置**: 在高德控制台配置允许的域名
4. **浏览器权限**: 地理定位功能需要浏览器定位权限
5. **数据限制**: 大量轨迹点可能影响性能，建议分段加载

## 🐛 常见问题

### Q: 地图不显示怎么办？
A: 
1. 检查控制台是否有错误信息
2. 确认 API Key 是否正确配置
3. 检查网络连接是否正常
4. 确认 API Key 是否有访问权限
5. 检查是否配置了正确的安全密钥

### Q: 如何接入真实的车辆数据？
A: 
1. 修改 `src/services/trackingService.js`
2. 替换模拟数据接口为实际 API
3. 调整数据格式适配
4. 添加认证和错误处理

### Q: 如何保存轨迹数据到服务器？
A: 
1. 在 `vehicleStore` 中添加保存方法
2. 创建 API 服务调用后端接口
3. 在适当的时机触发保存
4. 添加加载历史数据功能

### Q: 如何添加更多地图图层？
A: 
1. 在 `MapView.jsx` 中添加图层初始化
2. 使用高德地图图层 API
3. 添加控制开关
4. 优化图层性能

### Q: 如何优化性能？
A: 
1. 使用虚拟滚动显示大量车辆
2. 轨迹点抽稀显示
3. 使用 Web Worker 处理计算
4. 懒加载历史数据
5. 优化地图渲染
